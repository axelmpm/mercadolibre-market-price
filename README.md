# Mercado Libre Price Intelligence

A data science project for analyzing product prices in the Argentine e-commerce market using data from Mercado Libre Argentina.

The long-term goal is to build a system capable of estimating the **market price of a product** based on comparable listings and identifying products that may be priced above or below their expected market value.

## Problem

Online marketplaces can contain hundreds or thousands of listings for similar products, with significant differences in price, condition, specifications, and seller characteristics.

This project aims to answer questions such as:

- What is the typical market price of a product?
- What price range can be considered reasonable?
- Which characteristics explain differences in price?
- Is a particular listing relatively cheap or expensive compared with similar products?
- How do product prices change over time?

## Data Source

Data will be collected from Mercado Libre Argentina using the official Mercado Libre API.

The initial version of the project will focus on a single product category to develop and validate the data collection and analysis pipeline before expanding to additional categories.

Official API documentation:  
https://developers.mercadolibre.com.ar/

## Project Status

🚧 **Early development**

Current goals:

- Set up the project structure and development environment
- Explore the Mercado Libre API
- Select the initial product category
- Collect an initial sample of listings
- Understand the available attributes and data quality

Future iterations may include historical price tracking, automated data collection, statistical analysis, machine learning models for price estimation, and an API or application for querying estimated market prices.
